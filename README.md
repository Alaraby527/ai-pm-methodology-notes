## 为什么有这个仓库

在做 AI 产品项目的过程中，我发现一个问题：**每次遇到类似的问题（怎么写 PRD、怎么做评测、怎么分析用户痛点），都要重新翻聊天记录、重新搜索、重新整理。**

知识管理不是"收藏文章"，而是"把经验提炼成可复用的方法"。这个仓库的每一篇文档都遵循同一个原则：

1. **从实践中来**：不是从书本上抄的理论，而是在项目中遇到问题后总结的方法
2. **有模板可套用**：每篇文档都有可直接使用的框架或模板，不是空谈
3. **有质量标准**：明确"什么是好的"，而不是只说"要做用户调研"
4. **持续迭代**：随着项目经验增加，方法会更新，旧版本保留在 git 历史中
